\# Research Prototype



\## Class-Imbalance and Cross-Dataset Generalization Aware Skin Disease Classification



This project develops a reproducible machine learning prototype based on the research methodology developed in the Research Methodology Lab.



The currently available dataset contains binary dermatological sign annotations rather than the clinical/dermoscopic image dataset originally proposed for CNN-based classification.



Therefore, the current MVP focuses on reproducible prediction using the available tabular sign data. The limitation is documented, and the architecture can be extended to image-based CNN experiments when suitable image data becomes available.
